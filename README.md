# RomPP

Binary file comparison tool with 4 manual slots and a chip-style memory visualization.

## Run

```bash
python main.py
```

## Notes

- Colors: `00` = red, `FF` = blue, other bytes = green.
- Each slot is loaded manually with the `Load...` button (or click the ROM view).
- B/P = bytes per pixel block, computed automatically to fill a 64x32 grid.
